# 연결 상태

- 설치: `codex plugin marketplace add Ark-Point/gisul`, 이어서 `codex plugin add gisul@arkpoint`. 비공개 저장소 접근 권한이 필요하다.
- 로그인: 플러그인의 연결 UI에서 GitHub 계정을 연결한다. 필요하면 `codex mcp login gisul --scopes skills:read,skills:write`를 사용한다.
- 조직 확인 실패: `Ark-Point` 초대 수락 여부와 GitHub 앱의 조직 접근 허용을 확인한다.
- 취소·만료: 플러그인은 유지하고 Codex에서 로그인을 다시 시작한다. 토큰을 채팅에 붙여넣지 않는다.
- 서비스 확인 실패: 잠시 후 다시 시도한다. 조직 탈퇴나 빈 카탈로그로 단정하지 않는다.
- 연결 완료: 새 대화에서 “Gisul에서 이 작업에 맞는 스킬을 찾아줘”라고 요청한다.
- 편집 도구 없음: 이전 읽기 전용 연결이라면 GitHub 연결을 한 번 다시 승인한다. 새 연결에서 승인한 읽기·편집 권한은 토큰 갱신에도 유지된다. 별도 편집자 등록이나 개인 토큰 입력은 필요하지 않다.
- 편집 요청이 GitHub에서 거절됨: 연결한 계정의 저장소 접근 권한, GitHub 조직의 앱 접근 정책 또는 브랜치 보호를 확인한다. 저장·게시가 성공했다고 말하지 않는다.

노트북과 맥미니는 같은 클라이언트 설치 과정을 사용한다. 실행 중인 개인 연결을 교체할 때는 팀 로그인과 검색·읽기가 성공한 후 중복 연결을 정리한다.
