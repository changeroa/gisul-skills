# OpenClaw contribution lessons

Source snapshot: 2026-09-29. These are examples, not universal repository requirements. The four PRs were open at inspection time; none is evidence of a merge.

- [Raw model retry, #160803](https://github.com/openclaw/openclaw/pull/160803): source-level regression coverage was strengthened with an isolated real Gateway and a controlled HTTP provider stub. The trace showed the actual retry request losing the original task before the fix and retaining it afterward. Cold one-worker wall time (53.6 s) differed greatly from CI assertion time (5 ms and 3 ms); label measurements accordingly.
- [CLI cron lane wait, #160804](https://github.com/openclaw/openclaw/pull/160804): fixing watchdog reporting exposed an adjacent cancellation obligation. The revision passed the owner's abort signal into the queue and demonstrated cancellation settling while the predecessor still ran. Retaining a cron slot during an unbounded queue wait remained an explicit scheduler-owner decision, even with sufficient proof and no remaining concrete patch finding.
- [Restart cleanup warning, #160805](https://github.com/openclaw/openclaw/pull/160805): a real invalid SQLite fixture and the real logger proved a missing diagnostic. The contribution did not claim to prevent unwanted restarts, a consequence that had not been demonstrated.
- [Media cleanup warning, #160806](https://github.com/openclaw/openclaw/pull/160806): an OS-refused deletion proved the real warning path. Checks also showed cleanup continuing for the next artifact and remaining quiet for an already-missing artifact. The claim was diagnostic visibility, not changed retention.
- A prepared fix for [#160534](https://github.com/openclaw/openclaw/issues/160534) was withheld when the final publication check found it already resolved by [#160584](https://github.com/openclaw/openclaw/pull/160584). Preparation is not a reason to publish redundant work.
- The candidate ledger dropped other issues after reading prior closed PRs, unavailable live-platform proof requirements, active contributor comments, or a request for a shared ownership design. Labels suggesting an easy fix were not treated as proof of suitability.
- CI timeout/cancellation and unrelated-looking failures were kept separate from local focused passes. Their logs and limits belong with the claims they qualify; they do not justify silently marking all checks successful.
