# 세션 준비·진행·디브리프

## 진행 전 게이트

동의·중단권·보상·자료 처리 범위가 정해지기 전에는 기록을 시작하지 않는다.
관찰자와 녹음·전사 도구를 숨기지 않는다. 녹음 거절 시 동의된 노트 등 대안을 사용한다.
외부 처리 서비스 사용은 연구 참여 동의와 별개로 허용 범위를 확인한다.
화면 공유 전 사적 알림·문서·연락처가 노출될 수 있음을 정직하게 안내한다.
업무 평가·감사 목적이 아니라면 그렇게 설명하되 실제 기밀 범위 이상을 보장하지 않는다.

- 진행자는 흐름과 안전을, 기록자는 사실·발언·시점을 담당한다.
- 관찰자는 개입하지 않고 추가 질문을 기록해 정해진 시점에 전달한다.
- 파일럿에서 질문 이해, 과업 현실성, 시간, 연결·기록 저장, 종료 안내를 점검한다.
- 중단·피로·기술 장애·도움 요청에 대한 개입 기준과 대체 진행안을 준비한다.
- 세션 사이 자료를 저장하고 이전 참가자의 입력·로그인·개인정보를 제거한다.
- 진행자 휴식과 기록 정리 시간을 확보한다. 고정 세션 수를 모든 상황에 강제하지 않는다.

## 인터뷰: 경험을 탐색한다

최근 구체적인 사건에서 시작해 계기 → 목표 → 행동 → 도구·사람 → 막힌 지점 → 결과를 따라간다.
“이 기능이 편리하지 않나요?”처럼 평가 방향을 심는 질문을 피한다.
“그때 어떻게 처리하셨나요?”, “그 다음에는 무엇을 하셨나요?”처럼 중립적으로 묻는다.
사실 확인에는 닫힌 질문을 쓸 수 있지만 탐색 전체를 예/아니오로 끝내지 않는다.
추가 질문은 의도를 확인하는 수단이지 끝없이 이유를 캐묻는 심문이 아니다.
참가자가 제안한 기능을 곧바로 요구사항으로 채택하지 말고 해결하려는 일을 확인한다.
기억에 의존한 설명과 직접 관찰한 사건을 별도 기록한다.

## 맥락 관찰: 업무를 방해하지 않는다

화면 외 다른 도구·사람·서류·중단·인수인계를 질문에 필요한 범위에서 관찰한다.
시간에 민감하거나 위험한 작업은 중간에 질문하지 않고 안전한 시점에 확인한다.
우회 행동을 사용자 오류로 평가하기 전에 해당 환경에서 필요한 이유를 묻는다.
화면 공유로 보지 못한 물리·사회 환경을 관찰한 것처럼 쓰지 않는다.
방문·종료 신호와 참여자의 시간을 존중하며 동의 밖 인물·자료는 수집하지 않는다.

## 사용성 테스트: 경로를 가르치지 않는다

상황과 목표만 제시한다. 예: “다음 주 예약을 다른 날로 바꾸고 결과를 확인해 주세요.”
정답 메뉴·버튼명이나 절차를 넣어 탐색 능력을 미리 해결하지 않는다.
생각 말하기를 요청하되 침묵을 모두 채우거나 매 행동의 이유를 요구하지 않는다.
“지금 무엇을 생각하고 있나요?”처럼 중립적으로 확인하고 제품을 설명·방어하지 않는다.
참여자가 멈춰도 곧바로 구조하지 않는다. 사전 기준·도움 요청·안전을 기준으로 판단한다.
도움 전 상태, 개입 시점·내용·이유, 도움 후 결과를 기록한다.
과업 실패, 제품·프로토타입 장애, 기술적 기록 실패, 참가자 중단을 구별한다.
제품이 고장 나 다른 대화로 바뀌면 연구 모드를 바꾸고 원래 검증 결과를 미확인으로 남긴다.
무진행자 테스트는 실시간 후속 질문이 없으므로 과업·중단·지원 안내를 먼저 검증한다.

## 감정·안전·철회

“시선을 돌렸다”는 관찰이다. “제품을 불신했다”는 확인되지 않은 심리 해석이다.
감정·동기는 참가자가 직접 설명한 범위에서 자기 보고로 기록한다.
표정·말투·시선으로 감정 점수, 성격, 거짓말 여부를 추정하거나 생성하지 않는다.
불편해 보이는 신호는 단정 대신 계속할 의사를 확인할 계기로 삼는다.
위험·민감정보 노출·중단 요청 시 수집을 멈추고 해당 구간의 보관·삭제를 확인한다.
철회 요청은 약속한 절차대로 처리하고 원자료와 식별 가능한 파생 기록까지 추적한다.
익명 집계·이미 공유된 결과의 회수 가능 범위를 확인해 정직하게 알린다.
보상은 긍정 응답·과업 성공을 조건으로 하지 않으며 중단자를 불이익으로 압박하지 않는다.

## 디브리프와 변경 이력

1. 각자 관찰한 사실·기록 위치·의문을 독립적으로 적는다.
2. 반복·차이·미확인 해석과 개입의 영향을 비교한다.
3. 녹음·노트가 실제 저장됐는지, 누락·유도·모집 부적합이 있는지 점검한다.
4. 다음 세션의 변경 여부를 정하고 이유·버전·적용 세션을 기록한다.
5. 원래 질문의 답변 상태와 새 질문을 구분하고 공유 자료를 잠정 상태로 표시한다.

목소리 큰 관찰자의 결론이나 팀 다수결이 참여자 증거를 대체하지 않는다.
정량 비교 조건을 바꿨다면 자료를 분리하거나 분석 한계를 명시한다.
종료 시 남은 개인정보·자료·보상·철회 후속 조치의 책임자를 확인한다.
