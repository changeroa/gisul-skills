# 방법과 표본 선택

## 질문과 주장 범위를 맞춘다

사용 가능한 도구나 팀의 취향으로 질문을 바꾸지 않는다.
각 질문에 필요한 관측, 대상, 비교 조건, 분석 단위와 의사결정 시점을 적는다.

| 필요한 증거 | 후보 방법 | 한계와 보완 |
| --- | --- | --- |
| 최근 경험·목적·판단·우회 | 사건 중심 인터뷰 | 기억·자기 보고의 한계, 실제 행동 관찰로 보완 |
| 도구·사람·환경 사이 실제 업무 | 맥락 관찰 | 관찰자 영향, 보이지 않는 상황과 안전한 질문 시점 기록 |
| 특정 화면에서 과업을 수행하는 과정 | 사용성 테스트 | 과업·힌트·실험 환경 영향, 실제 이용 맥락과 차이 기록 |
| 정보 분류 언어·기대 구조 | 카드 분류 | 설명과 군집을 함께 보고 실제 탐색 과업으로 확인 |
| 구조 안에서 목적지를 찾는 경로 | 트리 테스트 | 시각적 화면·콘텐츠 이해 전체를 검증하지 않음 |
| 빈도·규모·변화 | 계측·설문 | 분모·계측 누락·응답 편향·표본의 한계 확인 |
| 대안의 성과 차이 | 적합하게 설계한 비교 실험 | 무작위화·검정력·중단 규칙·부작용 지표 필요 |
| 빠른 UI 위험 가설 | 전문가·에이전트 리뷰 | 실제 사용자 관찰·성공률이 아님 |

인터뷰로 발견한 설명을 설문으로 범위 확인하거나, 계측 이상 구간을 관찰로 탐색할 수 있다.
서로 다른 방법의 결과가 다르다고 어느 하나를 버리지 않는다. 먼저 대상·상황·정의가 같은지 본다.
여러 방법을 쓰더라도 같은 자료의 재가공은 독립 증거가 아니다.

## 모집 적합성

- “누구나 사용한다”를 대상 정의로 쓰지 않는다. 역할·핵심 행동·최근 경험·환경으로 나눈다.
- screener에는 실제 경험을 확인할 질문과 포함·제외 기준을 적는다.
- 원하는 응답이나 정답 조건을 노출해 지원자가 자신을 맞추게 하지 않는다.
- 집단별 할당은 비교하려는 차이와 연결한다. 인구통계 균형만으로 대표성을 주장하지 않는다.
- 기존 이용자 모집만으로 비사용자·이탈자·잠재 수요를 설명하지 않는다.
- 고객사 추천·자발적 지원·특정 시간 참여 가능자의 편향을 기록한다.
- 전문가 업무를 일반인으로 대신했다면 탐색 자료로 구분하고 해당 업무의 결론은 제한한다.
- 예비 연구는 불완전한 표본으로 시작할 수 있지만 표본의 차이를 숨기지 않는다.
- 모집 목표, 접촉·응답·참여·중도 종료·분석 포함 수와 제외 이유를 구분한다.

## 표본과 종료 조건

정성 탐색은 중요한 역할·상황의 차이와 새로운 설명이 남는지를 점검한다.
새로운 답이 적어져도 빠진 집단이나 고위험 예외가 있으면 “모두 확인”으로 닫지 않는다.
종료 이유는 질문별 학습 충분성, 남은 불확실성, 비용·일정 제약을 구분해 기록한다.
숫자 하나를 보편적인 참가자 수나 포화 기준으로 고정하지 않는다.

정량 연구는 분석 단위, 모집단, 추출·배정 방식, 필요한 정밀도 또는 탐지할 효과를 먼저 정한다.
통계 주장이 필요하지만 표본 설계·분석을 검증할 수 없으면 기술 통계와 한계까지만 보고한다.
작은 편의 표본의 비율을 전체 사용자 비율로 일반화하지 않는다.
참가자의 여러 과업·반복 응답을 독립적인 여러 사람으로 세지 않는다.

## 측정과 비교 계약

1. 이벤트·척도·성공·실패·도움·중도 종료의 정의를 수집 전에 정한다.
2. 분자·분모, 누락·제외 규칙, 측정 기간·단위와 대상 버전을 명시한다.
3. 도구가 실제 의도한 사건을 수집하는지 파일럿으로 확인한다.
4. 실험은 주 지표·부작용 지표·배정·기간·중단 규칙을 사전에 정한다.
5. 중간 결과가 유리해 보인다는 이유로 종료하거나 지표·대상을 바꾸지 않는다.
6. 변경이 필요하면 이유와 시점을 기록하고 기존 자료와의 비교 가능성을 재평가한다.
7. 결과에 표본 크기·분포·불확실성과 모집·계측 한계를 함께 제시한다.

think-aloud, 진행자 도움, 서로 다른 기기·과업 순서는 시간·완료율에 영향을 줄 수 있다.
같은 조건으로 보정할 수 없으면 단순 전후 차이를 개선 효과로 부르지 않는다.
계측으로 보이는 상관과 원인을 구분하고 후속 취소·오류·지원 부담 같은 부작용도 본다.

## 선택 결과에 남길 것

`결정 / 질문 / 방법 / 대상·모집 / 분석 단위 / 얻을 증거 / 못 얻는 증거 / 종료 조건 / 다음 검증`.
확보하지 못한 조건 때문에 방법이 바뀌면 기존 질문이 여전히 답해지는지 다시 확인한다.
