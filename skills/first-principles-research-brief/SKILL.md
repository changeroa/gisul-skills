# 낯선 분야 제1원리 리서치

## 실행 절차

1. 사용자의 질문에서 **대상 분야**, **이해하려는 이유**, **현재 상황**, **사용 가능한 도구**, **원하는 결정**을 추출한다. 정보가 없어도 안전한 가정을 표시해 진행하고, 분석 질문이 한 문장으로 고정되면 완료한다.

2. [방법의 출처와 해석 경계](references/method.md)를 읽고 1차 자료를 우선 조사한다. 교과서·공식 문서·원 논문·발명자나 책임자의 원문 발언을 찾고, 최신성이 중요한 사실은 현재 자료로 검증한다. 각 주장에 URL, 발행 주체, 날짜, 자료 유형을 기록하고, 원문과 후대의 재구성·해석을 구분하면 완료한다.

3. 분야의 지형을 설명한다. 핵심 개념과 작동 원리를 비전문가의 언어로 정의하고, 주요 구성요소·인과관계·제약을 식별한다. 모르는 부분과 논쟁 중인 부분을 별도로 표시하고, 독자가 “무엇이 어떻게 작동하는지”를 5문장 이내로 설명할 수 있으면 완료한다.

4. 기존 해법을 조사한다. 대표 접근 2–5개에 대해 누가, 어떤 조건에서, 왜 선택했는지와 성과·한계를 비교한다. 단순 사례 나열을 피하고, 반복되는 가정과 관행을 추출하면 완료한다.

5. 기존 해법을 사실·제약·관행으로 분해한다.
   - **사실:** 검증된 작동 원리나 데이터
   - **제약:** 지금도 반드시 지켜야 하는 조건
   - **관행:** 과거 조건에서 생겼지만 바꿀 수 있는 선택
   각 항목에 근거 또는 추론 표시를 붙이고, 다른 결과를 막는 핵심 가정이 드러나면 완료한다.

6. 현재 조건에서 처음부터 다시 설계한다. 목적, 성공 기준, 이용 가능한 도구, 달라진 환경을 명시하고 “과거 방식이 없었다면 무엇을 만들 것인가?”를 답한다. 제안마다 기존 방식과 달라지는 점, 기대 효과, 위험, 가장 작은 검증 실험을 연결하면 완료한다.

7. 결과를 **하나의 자체 포함 HTML 파일**로 만든다. [HTML 템플릿](templates/research-brief.html)의 구조와 디자인 토큰을 사용하되 내용에 맞게 섹션을 조정한다. 외부 CDN·원격 폰트·JavaScript 없이 열리고, 모바일·데스크톱·인쇄에서 읽히게 만든다. 다음 시각자료를 반드시 포함하면 완료한다.
   - 상단의 한 문장 결론과 신뢰도 배지
   - 기초자료 → 기존 해법 → 가정 분리 → 재설계 4단계 흐름도
   - 기존 접근 비교 카드 또는 표
   - 사실·제약·관행을 구분하는 시각 블록
   - 제안, 위험, 최소 실험을 연결하는 실행 지도
   - 번호가 붙은 근거 목록과 본문의 대응 링크

8. 품질을 검증한다. HTML 파서 오류, 끊어진 내부 앵커, 가로 스크롤, 대비 부족, 작은 본문 글자, 출처 없는 핵심 주장, 사실과 추론의 혼합을 점검한다. 브라우저에서 390px와 1440px 너비로 열어 시각적으로 확인하고, 인쇄 미리보기에서도 정보가 사라지지 않으면 완료한다.

## 판정 원칙

- “누가 만든 공식 N단계 방법론”과 후대 편집자가 재구성한 프레임을 구분한다.
- 원문에 없는 번호·용어·확신을 원저자의 주장처럼 쓰지 않는다.
- 선행 지식은 모방의 정답이 아니라 가능성과 가정을 찾는 재료로 쓴다.
- 불확실한 번역·청취·전사는 원문 표기와 대안을 함께 제시한다.
- 결론의 강도는 가장 약한 핵심 근거보다 세게 쓰지 않는다.
- 사용자가 요청한 언어로 작성하되, 고유명사와 핵심 원어는 첫 등장에 병기한다.

## 납품물

- 응답에는 결론 2–4문장, HTML 파일 링크, 핵심 한계만 적는다.
