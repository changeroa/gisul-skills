# 운영 비용과 최적화 실익

실제 대상 리소스만 집계한다. 실제 청구액, 사용량×단가의 공제 전 추정액, 포함 사용량·무료 구간·할인 적용 후 비용, 공유 비용과 배분 가정을 구분한다. 실행 환경·CDN·트래픽/전송·DB·객체 저장소·로그 등 존재하는 비용 항목만 사용한다.

현재 공식 요금 자료와 실제 계약/청구 조건을 확인한다. 확인하지 못하면 단가·절감액을 확정하지 않는다. 실사용 과금과 할당 자원 과금을 구분하고 MB/MiB/GB/GiB, 초/시간, 통화·요금 기준일을 명시한다.

저장량의 한 시점 관측을 월간 저장 비용과 동일시하지 않는다. 단기 사용량을 월간으로 환산할 때 계산식·기간·가정·변동성을 표시한다. 공유 비용을 근거 없이 운영 서비스에 전액 배정하지 않는다.

개선안마다 예상 절감액/범위, 계산식·가정, 성능·안정성 영향, 구현/운영 복잡도, 지금 실행할지 규모 증가 후 검토할지를 남긴다. 소액 절감을 위해 사용자 지연·장애 위험을 크게 늘리지 않는다. 비용이 작아도 데이터 누적·작업 중복 위험을 무시하지 않는다.

불필요한 keep-alive, 과도한 로그·polling·LIST, 반복 조회·중복 작업, 불필요한 전송 등 실제 관측된 낭비를 찾는다. 공급자 변경이나 새 인프라 도입은 검증된 실익이 있을 때만 검토한다.
