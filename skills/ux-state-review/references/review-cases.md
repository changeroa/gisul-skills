# 회귀 검토 사례

관련 사례만 골라 현재 제품의 실제 정책과 데이터로 재현한다. 아래 기대 결과는 명시된 가정에 한한다.

| 상황과 가정 | 확인할 결과 | 놓치기 쉬운 반례 |
|---|---|---|
| 제작정보 저장 완료가 새 생성의 선행조건이고 아직 미작성 | 작성 위치를 안내하고 생성에만 필요한 호출은 실행하지 않음 | 버튼만 막고 결과 조회 오류나 재시도를 계속 표시 |
| 필수 입력을 채웠지만 저장이 실패 | 작성 내용을 보존하고 저장 실패를 알림; 저장이 기준인 기능은 열리지 않음 | 클라이언트 초안만으로 준비 완료 처리 |
| 선행정보 저장에 성공 | 정해진 재확인으로 준비 상태를 갱신하고 다음 과업으로 진행 | 성공 토스트 뒤 과거 오류와 비활성화가 남음 |
| 준비된 대상의 결과 조회가 통신 실패 | 실제 실패와 유효한 재시도 제공 | 모든 실패를 미작성 안내로 치환 |
| 준비 상태 조회 자체가 실패 | 상태를 확인할 수 없음을 표시하고 적절한 복구 제공 | false 기본값으로 미작성 확정 |
| 검색 결과가 0건 | 검색 조건 수정·초기화 등 맥락에 맞는 행동 | 첫 이용 설정 안내나 시스템 장애 표시 |
| 새 생성은 막혔지만 기존 결과 조회는 허용 | 기존 결과 탐색을 유지하고 생성만 제한 | 전역 readiness 가드로 다운로드까지 차단 |
| 여러 병원 중 일부만 준비 완료 | 병원별 판단, 준비된 대상은 정상 동작 | 하나가 미완료라 전체 화면 차단 |
| 병원 전환 중 이전 요청이 늦게 완료 | 현재 대상과 일치하는 데이터만 표시 | 이전 병원의 오류·콘텐츠가 새 대상에 남음 |
| 같은 신청이 이미 확인 대기 중인 충돌 응답 | 기존 신청 상태를 이해하고 확인할 경로 제공 | 무한 재전송 유도 또는 무조건 성공 처리 |

리뷰만으로 확정하기 어려운 사용자 조사 과업 예: “이 병원에서 첫 콘텐츠를 만들 준비를 마쳐 주세요.” 참가자가 안내를 발견하고, 저장의 성공 여부와 다음 행동을 이해하는지 관찰한다. “제작정보 탭을 누르세요”처럼 정답 경로를 알려주지 않는다.
